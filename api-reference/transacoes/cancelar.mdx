<Warning>
  **Esta é uma rota interna do painel, não da API pública.** Ela aceita apenas a sessão do painel, não uma chave de API (`sk_test_` / `sk_live_`), e pode mudar sem aviso.

  Para cancelar uma cobrança pela API, use [`DELETE /api/v1/charges/{uuid}`](/api-reference/cobrancas/cancelar). Ela identifica a cobrança pelo `uuid` e só cancela cobranças da sua conta.
</Warning>

## Visão Geral

Cancela uma transação que ainda não foi paga (`pendingBoleto` ou `pendingPix`). É a rota que o painel usa no botão de cancelar.

O `{id}` da rota é o `galaxPayId` da transação, o identificador dela no processador de pagamento. Não é o `id` interno da transação nem o `uuid` da cobrança.

A rota só cancela transações da sua conta. Uma transação que não existe ou que é de outra conta responde `404` com a mensagem "Transação não encontrada", sem cancelar nada.

<Note>
  Para transações já pagas, use o [estorno](/api-reference/cobrancas/reembolsar), não o cancelamento.
</Note>

## Cancelar pela API pública

O equivalente na API pública é [Cancelar Cobrança](/api-reference/cobrancas/cancelar):

<CodeGroup>

```bash cURL
curl -X DELETE https://garu.com.br/api/v1/charges/6f1c9b2e-4a7d-4f0b-9a3e-1d2c3b4a5e6f \
  -H "Authorization: Bearer sk_test_sua_chave_api"
```

```javascript JavaScript
const response = await fetch(
  `https://garu.com.br/api/v1/charges/${chargeUuid}`,
  {
    method: 'DELETE',
    headers: { Authorization: `Bearer ${process.env.GARU_API_KEY}` }
  }
);

const { canceled } = await response.json();
```

```python Python
import os
import requests

response = requests.delete(
    f"https://garu.com.br/api/v1/charges/{charge_uuid}",
    headers={"Authorization": f"Bearer {os.environ['GARU_API_KEY']}"},
)

print(response.json()["canceled"])
```

</CodeGroup>

**Resposta (200 OK):**

```json
{ "canceled": true }
```

## Resposta da rota interna (200 OK)

```json
true
```

## Erros Comuns

<AccordionGroup>
  <Accordion title="401 - Não autorizado">
    **Solução:** Esta rota não aceita chave de API. Use [`DELETE /api/v1/charges/{uuid}`](/api-reference/cobrancas/cancelar).
  </Accordion>

  <Accordion title="404 - Transação não encontrada">
    ```json
    {
      "statusCode": 404,
      "timestamp": "2026-09-30T21:00:00.000Z",
      "path": "/api/transactions/12345",
      "message": "Transação não encontrada"
    }
    ```
    **Solução:** Confira se o `{id}` é o `galaxPayId` de uma transação **da sua conta**. Uma transação de outra conta responde exatamente como uma que não existe.
  </Accordion>

  <Accordion title="400 - Transação de outro processador">
    **Problema:** A transação foi processada por outro provedor de pagamento, e o cancelamento por esta rota ainda não está disponível para ele.

    **Solução:** Cancele a cobrança direto no painel do provedor.
  </Accordion>
</AccordionGroup>

## Exemplo: Cancelar Boletos Pendentes Antigos

Pela API pública, liste as cobranças pendentes e cancele cada uma pelo `uuid`:

```javascript
async function cancelarBoletosPendentesAntigos(diasAntigos = 7) {
  const limite = new Date(Date.now() - diasAntigos * 24 * 60 * 60 * 1000);
  const params = new URLSearchParams({
    status: 'pending',
    paymentMethod: 'boleto',
    createdBefore: limite.toISOString(),
    limit: '100'
  });

  const response = await fetch(`https://garu.com.br/api/v1/charges?${params}`, {
    headers: { Authorization: `Bearer ${process.env.GARU_API_KEY}` }
  });
  const { data: cobrancas } = await response.json();

  const canceladas = [];
  for (const cobranca of cobrancas) {
    await fetch(`https://garu.com.br/api/v1/charges/${cobranca.uuid}`, {
      method: 'DELETE',
      headers: { Authorization: `Bearer ${process.env.GARU_API_KEY}` }
    });
    canceladas.push(cobranca.uuid);
  }

  console.log(`${canceladas.length} cobranças canceladas`);
  return canceladas;
}
```
