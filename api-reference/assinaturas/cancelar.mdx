## Visão Geral

Cancele uma assinatura de duas formas: imediatamente (cliente perde acesso na hora) ou agendado para o fim do período pago (cliente mantém acesso até a data de renovação). Sem `cancelAtPeriodEnd` no corpo, o cancelamento fica **agendado**.

<Warning>
  Esta página pedia o campo `cancelImmediately`. A API não lê esse campo: sem `cancelAtPeriodEnd`, o
  cancelamento fica agendado para o fim do período. Se a sua integração envia
  `cancelImmediately: true`, troque por `cancelAtPeriodEnd: false`.
</Warning>

## Cancelamento Imediato

O cliente perde acesso imediatamente e nenhuma cobrança futura será realizada.

<CodeGroup>

```bash cURL
curl -X POST https://garu.com.br/api/subscriptions/100/cancel \
  -H "Authorization: Bearer sk_test_sua_chave" \
  -H "Content-Type: application/json" \
  -d '{
    "cancelAtPeriodEnd": false,
    "reason": "Cliente solicitou cancelamento"
  }'
```

```javascript JavaScript
const response = await fetch(
  'https://garu.com.br/api/subscriptions/100/cancel',
  {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.GARU_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      cancelAtPeriodEnd: false,
      reason: 'Cliente solicitou cancelamento'
    })
  }
);

const result = await response.json();
console.log(`Status: ${result.status}`); // "canceled"
```

```python Python
import requests
import os

url = "https://garu.com.br/api/subscriptions/100/cancel"
headers = {
    "Authorization": f"Bearer {os.environ['GARU_API_KEY']}",
    "Content-Type": "application/json"
}
payload = {
    "cancelAtPeriodEnd": False,
    "reason": "Cliente solicitou cancelamento"
}

response = requests.post(url, json=payload, headers=headers)
result = response.json()
print(f"Status: {result['status']}")  # "canceled"
```

</CodeGroup>

**Resultado:**
- Status muda para `canceled`
- Acesso revogado imediatamente
- Nenhuma cobrança futura
- Você recebe o webhook `subscription.cancelled`

## Cancelamento Agendado

O cliente mantém acesso até o fim do período pago atual.

<CodeGroup>

```bash cURL
curl -X POST https://garu.com.br/api/subscriptions/100/cancel \
  -H "Authorization: Bearer sk_test_sua_chave" \
  -H "Content-Type: application/json" \
  -d '{
    "cancelAtPeriodEnd": true,
    "reason": "Cliente optou por não renovar"
  }'
```

```javascript JavaScript
const response = await fetch(
  'https://garu.com.br/api/subscriptions/100/cancel',
  {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.GARU_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      cancelAtPeriodEnd: true,
      reason: 'Cliente optou por não renovar'
    })
  }
);

const result = await response.json();
console.log(`Cancelamento agendado: ${result.cancelAtPeriodEnd}`); // true
```

```python Python
import requests
import os

url = "https://garu.com.br/api/subscriptions/100/cancel"
headers = {
    "Authorization": f"Bearer {os.environ['GARU_API_KEY']}",
    "Content-Type": "application/json"
}
payload = {
    "cancelAtPeriodEnd": True,
    "reason": "Cliente optou por não renovar"
}

response = requests.post(url, json=payload, headers=headers)
result = response.json()
print(f"Cancelamento agendado: {result['cancelAtPeriodEnd']}")  # True
```

</CodeGroup>

**Resultado:**
- O status continua o mesmo (por exemplo, `active`), com `cancelAtPeriodEnd: true`
- Cliente mantém acesso até `currentPeriodEnd`
- Você recebe o webhook `subscription.updated`
- No fim do período, o status muda para `canceled`, e você recebe `subscription.cancelled`

## Parâmetros

<ParamField body="cancelAtPeriodEnd" type="boolean" default="true">
  `false` = cancelamento imediato. `true`, ou campo ausente = cancelamento no fim do período.
</ParamField>

<ParamField body="reason" type="string">
  Motivo do cancelamento (opcional, para registro interno).
</ParamField>

## Resposta de Sucesso

### Cancelamento Imediato (200 OK)

```json
{
  "id": 100,
  "status": "canceled",
  "cancelledAt": "2024-02-20T10:00:00.000Z",
  "cancelAtPeriodEnd": false,
  "endedAt": "2024-02-20T10:00:00.000Z"
}
```

### Cancelamento Agendado (200 OK)

```json
{
  "id": 100,
  "status": "active",
  "cancelledAt": "2024-02-20T10:00:00.000Z",
  "cancelAtPeriodEnd": true,
  "endedAt": null
}
```

`cancelledAt` é quando o cancelamento foi pedido. `endedAt` é quando a assinatura terminou: no cancelamento agendado, ele fica `null` até o fim do período.

## Erros Comuns

<AccordionGroup>
  <Accordion title="404 - Assinatura não encontrada">
    ```json
    {
      "statusCode": 404,
      "message": "Subscription not found"
    }
    ```
    **Solução:** Verifique se o ID da assinatura está correto.
  </Accordion>

  <Accordion title="400 - Assinatura já cancelada">
    ```json
    {
      "statusCode": 400,
      "message": "Subscription is already canceled"
    }
    ```
    **Solução:** A assinatura já foi cancelada anteriormente.
  </Accordion>
</AccordionGroup>
