## Visão Geral

Consulte o histórico completo de eventos de uma assinatura, incluindo pagamentos, mudanças de status, períodos de teste e cancelamentos.

## Exemplo de Requisição

<CodeGroup>

```bash cURL
curl -X GET https://garu.com.br/api/subscriptions/100/events \
  -H "Authorization: Bearer sk_test_sua_chave"
```

```javascript JavaScript
const response = await fetch(
  'https://garu.com.br/api/subscriptions/100/events',
  {
    headers: {
      'Authorization': `Bearer ${process.env.GARU_API_KEY}`
    }
  }
);

const events = await response.json();
events.forEach(event => {
  console.log(`${event.createdAt}: ${event.eventType}`);
});
```

```python Python
import requests
import os

url = "https://garu.com.br/api/subscriptions/100/events"
headers = {
    "Authorization": f"Bearer {os.environ['GARU_API_KEY']}"
}

response = requests.get(url, headers=headers)
events = response.json()

for event in events:
    print(f"{event['createdAt']}: {event['eventType']}")
```

</CodeGroup>

Este histórico é diferente dos [webhooks](/api-reference/webhooks): os tipos abaixo ficam só aqui, e os nomes não são os dos eventos enviados ao seu endpoint.

## Tipos de Evento

| Tipo | Descrição |
|------|-----------|
| `subscription.created` | Assinatura criada |
| `subscription.updated` | Dados da assinatura atualizados |
| `subscription.cancel_scheduled` | Cancelamento agendado para o fim do período |
| `subscription.reactivated` | Cancelamento agendado desfeito |
| `subscription.canceled` | Assinatura cancelada: na hora, por falhas de pagamento ou, no Pix Automático, pela autorização recusada ou cancelada no banco |
| `subscription.canceled_at_period_end` | Assinatura cancelada no fim do período, por um cancelamento agendado |
| `subscription.paused` | Assinatura pausada |
| `subscription.resumed` | Assinatura retomada após pausa |
| `subscription.status_updated` | O status mudou por um aviso do meio de pagamento |
| `billing.success` | Pagamento confirmado |
| `billing.failed` | Pagamento falhou; `retryCount` diz quantas falhas seguidas |
| `billing.max_retries_exceeded` | As falhas chegaram ao limite, e a assinatura foi encerrada |
| `billing.webhook_missed_alert` | O aviso de um pagamento esperado não chegou |
| `billing.auto_escalated_past_due` | Sem o aviso de pagamento, a assinatura foi para `past_due` |
| `payment_method_updated` | O cartão da assinatura foi trocado |
| `notification.renewal_reminder_sent` | Lembrete de renovação enviado ao cliente |
| `notification.trial_ending_sent` | Aviso de fim do período de teste enviado ao cliente |

## Campos do Evento

<ResponseField name="id" type="number">
  ID único do evento.
</ResponseField>

<ResponseField name="subscriptionId" type="number">
  ID da assinatura relacionada.
</ResponseField>

<ResponseField name="eventType" type="string">
  Tipo do evento (veja tabela acima).
</ResponseField>

<ResponseField name="eventData" type="object | null">
  Dados adicionais específicos do evento. O formato muda de um tipo para outro.
</ResponseField>

<ResponseField name="gatewayEventId" type="string | null">
  O id do aviso do meio de pagamento que gerou o evento, quando houve um.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Data e hora do evento (ISO 8601).
</ResponseField>

## Exemplo: Construindo um Billing History

```javascript
async function getBillingHistory(subscriptionId) {
  const response = await fetch(
    `https://garu.com.br/api/subscriptions/${subscriptionId}/events`,
    {
      headers: {
        'Authorization': `Bearer ${process.env.GARU_API_KEY}`
      }
    }
  );

  const events = await response.json();

  // Filtrar apenas eventos de pagamento
  const payments = events.filter(e =>
    e.eventType === 'billing.success' || e.eventType === 'billing.failed'
  );

  return payments.map(payment => ({
    date: payment.createdAt,
    status: payment.eventType === 'billing.success' ? 'Pago' : 'Falhou',
    // Só um pagamento confirmado traz o valor, como texto: "49.90"
    amount: payment.eventData.amount ?? null,
    error: payment.eventData.error ?? null
  }));
}

// Uso
const history = await getBillingHistory(100);
console.log('Histórico de Pagamentos:');
history.forEach(p => {
  const detail = p.amount ? `R$ ${p.amount}` : p.error;
  console.log(`${p.date}: ${p.status} - ${detail}`);
});
```
