## Visão Geral

Use este endpoint para atualizar as informações de um produto existente. Apenas os campos enviados serão atualizados.

## Parâmetros de Path

<ParamField path="uuid" type="string" required>
  UUID do produto a ser atualizado.
</ParamField>

## Parâmetros do Body

Todos os campos são opcionais. Envie apenas os que deseja atualizar.

<ParamField body="name" type="string">
  Novo nome do produto.
</ParamField>

<ParamField body="description" type="string">
  Nova descrição do produto.
</ParamField>

<ParamField body="value" type="number">
  Novo preço do produto em **Reais** (BRL decimal, ex: `347.00`), nunca em centavos. Envie `0` para deixar o produto sem preço; qualquer outro preço precisa ser de **pelo menos R$ 5,00**. De R$ 0,01 a R$ 4,99, ou um valor negativo, a API responde `400`.

  Omita o campo para manter o preço atual. A regra do mínimo só vale quando o pedido define um preço: um produto que já custava menos de R$ 5,00 continua vendendo, e um pedido que só troca o nome ou liga o PIX passa normalmente.
</ParamField>

<ParamField body="pix" type="boolean">
  Habilitar/desabilitar pagamento via PIX.
</ParamField>

<ParamField body="creditCard" type="boolean">
  Habilitar/desabilitar pagamento via cartão de crédito.
</ParamField>

<ParamField body="boleto" type="boolean">
  Habilitar/desabilitar pagamento via boleto.
</ParamField>

<ParamField body="pixAutomatic" type="boolean">
  Habilitar/desabilitar o [Pix Automático](/guias/pix-automatico) (débito recorrente do Pix) no produto. Enviar `false` impede **novas** assinaturas por Pix Automático nesse produto; as assinaturas já ativas continuam sendo cobradas normalmente.
</ParamField>

<ParamField body="installments" type="number">
  Novo número máximo de parcelas (1-12).
</ParamField>

<ParamField body="image" type="string">
  Nova URL da imagem do produto.
</ParamField>

<ParamField body="returnUrl" type="string">
  Nova URL de retorno após pagamento.
</ParamField>

<ParamField body="returnUrlButtonText" type="string">
  Novo texto do botão de retorno.
</ParamField>

<ParamField body="isSubscription" type="boolean">
  Transforma o produto em assinatura (`true`) ou em venda avulsa (`false`). Transformar um produto de assinatura em venda avulsa conta como definir o preço: o `value` guardado nele passa a ser o preço do link, e precisa ser `0` ou pelo menos R$ 5,00.
</ParamField>

## Exemplo de Requisição

<CodeGroup>

```bash cURL
curl -X PATCH https://garu.com.br/api/v1/products/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "Authorization: Bearer sk_test_sua_chave_api" \
  -H "Content-Type: application/json" \
  -d '{
    "value": 347.00,
    "installments": 6
  }'
```

```javascript JavaScript
const response = await fetch('https://garu.com.br/api/v1/products/a1b2c3d4-e5f6-7890-abcd-ef1234567890', {
  method: 'PATCH',
  headers: {
    'Authorization': `Bearer ${process.env.GARU_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    value: 347.00,
    installments: 6
  })
});

const product = await response.json();
console.log(`Produto atualizado: ${product.name} - R$ ${product.value}`);
```

```python Python
import requests
import os

url = "https://garu.com.br/api/v1/products/a1b2c3d4-e5f6-7890-abcd-ef1234567890"
headers = {
    "Authorization": f"Bearer {os.environ['GARU_API_KEY']}",
    "Content-Type": "application/json"
}
payload = {
    "value": 347.00,
    "installments": 6
}

response = requests.patch(url, json=payload, headers=headers)
product = response.json()
print(f"Produto atualizado: {product['name']} - R$ {product['value']}")
```

</CodeGroup>

  O `uuid` do produto **não muda** ao atualizar. O link de pagamento permanece o mesmo.
</Note>

## Erros Comuns

<AccordionGroup>
  <Accordion title="400 - Preço abaixo do mínimo">
    ```json
    {
      "statusCode": 400,
      "timestamp": "2026-09-30T21:00:00.000Z",
      "path": "/api/v1/products/a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "message": "O preço mínimo de um produto é R$ 5,00. Use R$ 0,00 para um produto sem preço."
    }
    ```
    **Solução:** Envie um `value` de pelo menos `5.00`, ou `0` para deixar o produto sem preço. Se você não quer mudar o preço, não envie `value`.
  </Accordion>

  <Accordion title="404 - Produto não encontrado">
    ```json
    {
      "statusCode": 404,
      "message": "Product not found"
    }
    ```
    **Solução:** Verifique se o UUID do produto está correto.
  </Accordion>

  <Accordion title="403 - Sem permissão">
    ```json
    {
      "statusCode": 403,
      "message": "Insufficient permissions"
    }
    ```
    **Solução:** Você só pode atualizar produtos criados com sua conta.
  </Accordion>
</AccordionGroup>
